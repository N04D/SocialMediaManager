# GitHub CI Evidence Promotion

Promotion is separate from evidence import. It records that a technically valid, trusted, fresh and reviewed package may be used for one exact commit.

Promotion does not mutate the evidence package or import attestation.

V0.1 does not promote evidence to `latest`, a branch, all descendants or all releases.

Readiness requires exact commit match, imported artifact, provider digest policy, valid package, zero required skips, signature policy, trusted origin, freshness, review and promotion.
