# Content Funnel Attribution

Website, social, and conversion metrics bind to the same content revision and publication targets. The funnel readmodel separates social engagement, link clicks, website visits, engaged visits, CTA clicks, conversions, and conversion value.

Attribution links use `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, and an opaque `smm_attribution_id`. No PII belongs in attribution parameters.
