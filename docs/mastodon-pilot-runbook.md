# Mastodon Pilot Runbook

Run a real pilot only with explicit local approval and credentials.

Preflight:

1. Check `git status --short`.
2. Confirm user-owned `content/` and `drafts/` files are outside scope.
3. Run the doctor.
4. Run fixture integration tests.
5. Confirm instance compatibility.
6. Confirm OAuth scopes.
7. Refresh requirements.
8. Check kill switches.
9. Check execution health.
10. Check analytics health.

Pilot:

11. Connect the test account.
12. Verify account identity.
13. Run session check.
14. Validate one approved text revision.
15. Prepare and confirm a plan.
16. Publish one public or unlisted test status.
17. Verify evidence and metrics.
18. Repeat with one JPEG or PNG plus alt text.
19. Run a LinkedIn + Mastodon multichannel plan.
20. Confirm analytics comparison warnings and unavailable denominators.

Missing credentials are not a technical failure.
