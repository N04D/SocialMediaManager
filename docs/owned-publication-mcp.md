# Owned Publication MCP

Read-only MCP-style helpers expose:

- `get_owned_publication_workspace`
- `get_article_with_channel_variants`
- `get_publication_plan`
- `get_publication_dependencies`
- `get_publication_execution_timeline`
- `get_publication_evidence`
- `get_reconciliation_queue`
- `get_content_funnel`
- `compare_channel_performance`
- `compare_content_revisions`
- `get_funnel_dropoffs`
- `get_cta_performance`
- `get_attribution_quality`

Every response includes exact binding to content item, content revision, channel variant, publication target, publication attempt, campaign, or analytics window where relevant.
