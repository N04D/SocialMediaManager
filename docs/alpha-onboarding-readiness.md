# Alpha Onboarding Readiness

The readmodel reports `alpha_setup_status`, `alpha_operational_ready`, `publishing_ready`, `analytics_ready`, `instrumentation_ready`, `ci_certification_ready`, `external_plugin_sandbox_ready`, and `production_ready`. `alpha_operational_ready` means authoring and first-publication flow are safe locally; it never implies production readiness. Missing Plausible, social channels, signer, or remote CI does not block minimal website alpha publishing.
