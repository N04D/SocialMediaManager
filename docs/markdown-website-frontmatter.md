# Markdown Website Frontmatter

Profiles are versioned and deterministic: `generic_yaml`, `hugo`, `jekyll`, `astro`, `eleventy`, and `next_mdx`.

Frontmatter uses a fixed key order, UTF-8, LF endings, scalar escaping, no Python object tags, and custom keys only from the selected profile allowlist. Revision binding fields remain present for verification, reconciliation, and analytics attribution.
