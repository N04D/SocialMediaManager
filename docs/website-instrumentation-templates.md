# Website Instrumentation Templates

Reference templates are provided for generic HTML/JavaScript, Astro, Hugo,
Jekyll, Eleventy, and Next.js under `templates/website-instrumentation/`.

Templates show script inclusion, page context, public markers, CTA bindings,
conversion bindings, provider bridge loading, consent hooks, and CSP guidance.
They contain no credentials and are not automatically installed in any website
repository. Operators must review and adapt them manually in the target static
site project.
