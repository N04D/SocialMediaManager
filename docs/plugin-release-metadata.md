# Plugin Release Metadata

A release contains `plugin.whl`, `plugin.release.json`, `plugin.sigstore.json`, `plugin.sbom.json`, and `plugin.compatibility.json`. Metadata binds plugin id, version, distribution name, wheel filename, wheel SHA-256, entrypoint group/name/object, SDK version, framework contracts, capabilities, permissions, signer policy, SBOM hash, compatibility hash, status, release channel, yanking, revocation, and state compatibility.
