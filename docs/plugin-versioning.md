# Plugin SDK Versioning

Patch releases may include bugfixes, docs, extra fakes, optional assertions, and safe optional health fields. Minor releases may add optional capabilities, optional model fields with defaults, helpers, template profiles, and non-breaking facades.

Major releases are required for mandatory methods, removed methods, semantic field changes, error semantic changes, lifecycle changes, context service removal, or capability behavior changes. Breaking changes require migration docs, deprecation warnings, compatibility periods, old and new contract tests, and changelog entries.
