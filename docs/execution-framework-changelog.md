# Execution Framework Changelog

## 0.1.0

- Added execution contract versions.
- Added `ExecutionAttempt`, `ExecutionLease`, retry decisions, reconciliation results, and uncertain resolutions.
- Added `PublicationExecutionService`.
- Added due-target selection with timezone normalization.
- Added atomic leases, heartbeats, release, and expiry recovery.
- Added dispatch into existing publish jobs with target/snapshot idempotency.
- Added worker reporting through execution service.
- Added reconciliation and aggregate plan status derivation.
- Added compact execution API and dashboard controls.
- Added execution tests and boundary checks.
