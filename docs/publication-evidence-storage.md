# Publication Evidence Storage

Evidence is typed and immutable: render evidence, Git commit evidence, remote push evidence, public URL evidence, social acknowledgments, social verification, media evidence, and analytics binding evidence.

Evidence stores safe IDs, checksums, relative paths, public URLs, remote IDs, timestamps, and verification status. It never stores private remotes with credentials, absolute sensitive paths, private keys, tokens, cookies, authorization headers, raw HTTP bodies, or full article bodies.
