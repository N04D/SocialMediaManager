# Website Instrumentation Changelog

## 0.1.0

- Added provider-neutral instrumentation contracts and manifest generation.
- Added opaque identifiers, page context, event envelope, consent modes, and
  property allowlists.
- Added dependency-free JavaScript runtime and Plausible browser bridge.
- Added static-site reference templates for generic HTML, Astro, Hugo, Jekyll,
  Eleventy, and Next.js.
- Added static verification, mapping drift detection, quality reports, CLI,
  API, MCP surface, operations readiness fields, and deterministic tests.
